### BaghNetra
*Offline-first AI and GIS system for camera-trap triage and individual tiger movement tracking.*

**Problem:** most camera-trap frames in a tiger reserve are empty (wind, rain, glare). Sorting them by hand takes biologists hundreds of hours and delays conservation decisions.

**Key features**
- Blank-frame triage with a **reversible quarantine**, so nothing is deleted immediately
- YOLOv8 wildlife detection, with **automatic masking of humans** for privacy
- **Individual tiger re-identification** from stripe patterns (metric learning)
- GIS analysis: home-range polygons and territory-shift alerts
- Runs **fully offline** on field laptops
- Uses synthetic demo data, so no real tiger locations are exposed

**Architecture:** React frontend, Node/Express API, separate Python FastAPI inference service

**Stack:** React · Node.js · Express · FastAPI · PyTorch · YOLOv8 · MongoDB

[Repository](https://github.com/shashankj015/test_baghnetra)

### City-Sync
*A multi-page web platform for city-level coordination.*

**Problem:** city services and the people who use them often live in separate tools. City-Sync puts residents and administrators in one system, each with their own view.

**Key features**
- Separate **Resident** and **Admin** dashboards
- A dedicated **Map** dashboard
- Sign-in and sign-up flow
- Standalone backend service
- Deployed and publicly accessible

**Stack:** HTML5 · Render

[Repository](https://github.com/devanshbhasme/City-Sync) &nbsp;·&nbsp; [Live demo](https://new-folder-wu2d.onrender.com/Home%20Page/home.html)
