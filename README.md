## About

I'm a Computer Science Engineering student who learns best by building things that have to work end to end: a frontend that talks to a backend, a deployment someone else can open, a feature that survives real use.

My interests sit across software development, data, and the problem-solving that connects them. I'd rather ship a small project that works than plan a big one that doesn't, and I use each project to find out what I don't know yet.
